## 📱 功能一览

| 模块 | 说明 | 页面 |
|------|------|------|
| **实时开穴** | 自动检测当前北京时间，SVG表盘显示时辰，四种算法同时开穴 | `/` |
| **📅 干支日历** | 月视图显示每日干支，点击日期查看该日午时开穴 | `/calendar/` |
| **🔍 择时查询** | 选择任意日期+时辰，四种算法同步出结果 | `/query/` |
| **📖 算法知识** | 五种择时开穴算法的理论说明与古籍出处 | `/knowledge/` |

## 🧪 算法正确性

所有算法均经过交叉验证，**6套测试全部通过** ✅

- 干支计算：以2000年1月1日（戊午日）为基准，验证到2024年春节（甲辰日）
- 五鼠遁时干：9组对照测试
- 纳子法：3组对照（心经少冲/神门、肝经曲泉/行间、脾经大都/商丘）
- 纳甲法：6组对照（甲日足窍阴→阳溪、乙日大敦、丙日少泽、戊日厉兑等）
- 灵龟八法：甲子日子时=余4巽卦、甲申日午时=余6乾卦
- 飞腾八法：甲日午时外关震、甲日申时公孙乾、乙日子时内关艮

## 💻 本地开发

```bash
# 克隆
git clone https://github.com/yzhi1065-bot/chrono-acu.git
cd chrono-acu

# 安装
npm install

# 启动开发服务器（热更新）
npm run dev

# 构建
npm run build

# 算法验证测试
npm run test
# 或 Python 验证
python3 verify.py
```

构建产物输出到 `docs/` 目录，可直接部署到 GitHub Pages。
