# 历法·子午灵龟 — 择时开穴工具

> 传统历法·子午流注·灵龟八法·飞腾八法·择时开穴 — Chrono-acupuncture time selection tool

基于《针灸大全》《针灸大成》等古籍，纯前端实现的传统时间针法择时开穴工具。

## 功能

- **📅 公历/农历日历** — 月视图查看每日干支
- **🕐 实时时辰表盘** — SVG 动画，显示当前时辰与四种开穴
- **🌿 纳子法** — 十二时辰当令经 + 补母泻子
- **☯️ 纳甲法** — 逐日按时开五输穴 + 原穴
- **🐢 灵龟八法** — 八脉交会穴配九宫八卦
- **🕊️ 飞腾八法** — 先天八卦纳甲取穴
- **⏱️ 养子时刻注穴法** — 每24分钟开一穴
- **📖 知识页面** — 算法说明与理论依据

## 算法正确性

所有算法均以交叉验证方式校验：
- 徐凤《针灸大全》逐日按时定穴诀（纳甲法）
- 《针灸大成》十二经纳支法（纳子法）
- 《扁鹊神应针灸玉龙经》飞腾八法
- 与 utoappia 子午灵龟 App 对照验证
- 单元测试覆盖 20+ 测试用例

## 技术栈

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Vitest (测试)
- 零运行时依赖（无后端，纯客户端计算）

## 本地开发

```bash
npm install
npm run dev
```

测试：

```bash
npm run test
```

## 部署

自动构建为静态页面，部署到 GitHub Pages。

```bash
npm run build
# docs/ 目录即为静态产物
```
